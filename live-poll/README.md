# 실시간 투표 (멘티미터 간단판)

발표 중에 참석자가 휴대폰으로 QR을 찍거나 코드를 입력해 들어와서 **객관식 투표**와 **주관식(단답)** 질문에 답하면, 발표 화면에 결과가 실시간으로 뜹니다.

- 화면: GitHub Pages (무료)
- 응답 저장 + 실시간 반영: Firebase Realtime Database (무료 요금제, 동시 접속 100명까지)

| 페이지 | 누가 | 주소 |
|---|---|---|
| `host.html` | 발표자 (질문 편집, 발표 화면) | `https://uredridinghood-cloud.github.io/codex/live-poll/host.html` |
| `index.html` | 참석자 (휴대폰) | `https://uredridinghood-cloud.github.io/codex/live-poll/` (QR로 접속) |

---

## 처음 한 번: Firebase 설정 (약 10분)

1. <https://console.firebase.google.com> 에 구글 계정으로 들어가서 **프로젝트 추가** → 이름 아무거나(예: `live-poll`) → Google 애널리틱스는 **사용 안 함** → 만들기
2. 왼쪽 메뉴 **빌드 → Realtime Database → 데이터베이스 만들기**
   - 위치: **싱가포르 (asia-southeast1)**
   - 보안 규칙: **잠금 모드로 시작**
3. Realtime Database의 **규칙** 탭 → 내용을 모두 지우고 이 폴더의 [`database.rules.json`](database.rules.json) 내용을 그대로 붙여넣기 → **게시**
4. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법** 탭 → **익명** → 사용 설정 → 저장
5. 왼쪽 위 톱니바퀴 **프로젝트 설정 → 일반** 맨 아래 **내 앱 → 웹(`</>`)** 아이콘 → 앱 닉네임 아무거나 → (Firebase 호스팅은 체크하지 않음) → 앱 등록
6. 화면에 나오는 `firebaseConfig = { ... }` 안의 값을 [`firebase-config.js`](firebase-config.js)에 그대로 붙여넣고 커밋
   - `databaseURL` 줄이 꼭 있어야 합니다. 없으면 2번(데이터베이스 만들기)을 먼저 하고 다시 복사하세요.
   - 이 값들은 공개되어도 괜찮습니다. 남이 데이터를 함부로 못 바꾸게 막는 건 3번의 규칙입니다.

> 설정 값을 저(Claude)에게 붙여 주시면 `firebase-config.js`에 넣어서 올려 드립니다.

## 발표 준비

1. `host.html` 열기 → **새 발표 만들기** (제목 + 관리 비밀번호)
2. 4자리 **참여 코드**가 생기고 질문 편집 화면이 나옵니다. 예시 질문 2개가 들어 있으니 고치거나 지우세요.
   - **객관식**: 보기 2~8개
   - **주관식(단답)**: 200자까지. 같은 답은 묶여서 크게 표시됩니다(띄어쓰기·대소문자 무시).
   - 고치면 자동 저장됩니다.
3. 편집 화면의 **참여 주소**를 내 휴대폰으로 열어서 미리 한 번 해 보세요.

**다른 컴퓨터(행사장 PC)에서 열 때**: `host.html` → **만들어 둔 발표 열기** → 참여 코드 + 관리 비밀번호. 한 번 열면 그 컴퓨터는 다음부터 비밀번호 없이 열립니다.

## 발표 당일

1. `host.html` → **발표 화면 열기 ▶** → `F` 키로 전체 화면
2. 처음엔 **입장 화면**(큰 QR + 코드 + 들어온 사람 이름)이 나옵니다.
3. `→` 키로 다음 질문을 열면 참석자 휴대폰에도 같은 질문이 바로 뜹니다.
4. 끝나면 **편집으로 → 결과 내려받기 (CSV)**. 엑셀에서 바로 열리고, 사람별 응답과 객관식 집계가 들어 있습니다.

| 키 | 동작 |
|---|---|
| `→` / `Space` / `PageDown` | 다음 질문 |
| `←` / `PageUp` | 이전 질문 |
| `0` / `Home` | 입장 화면(QR) |
| `R` | 결과 가리기 / 보이기 (가리면 응답 인원만 보임) |
| `L` | 응답 마감 / 다시 받기 |
| `F` | 전체 화면 |

화면 아래쪽 버튼 줄은 마우스를 올리면 진하게 보입니다. 리모컨(PageUp/PageDown)으로도 넘어갑니다.

- 참석자는 마감 전까지 답을 바꿀 수 있습니다. 질문을 넘기거나 마감하면 더 이상 바뀌지 않습니다.
- 참석자가 새로고침하거나 브라우저를 닫았다 열어도 같은 휴대폰이면 이어서 참여됩니다.
- 화면 위에 빨간 띠가 보이면 인터넷이 끊긴 것이고, 다시 연결되면 저절로 사라집니다.
- PPT와 같이 쓸 때는 `Alt+Tab`으로 브라우저와 오가면 됩니다.

## 70명 규모에서 알아둘 것

- Firebase 무료 요금제의 동시 접속 한도는 100명이라 70명 + 발표자 화면이면 충분합니다.
- 학교 와이파이에 한꺼번에 몰리면 느릴 수 있으니 "휴대폰 데이터로 접속해 주세요"라고 안내하는 편이 안전합니다.
- 발표 전날 휴대폰 3~4대로 처음부터 끝까지 한 번 해 보세요.

## 데이터 구조 (참고)

```
rooms/{코드}/meta          제목, 이름 받기 여부
rooms/{코드}/questions     질문 목록
rooms/{코드}/state         지금 열린 질문, 마감 여부, 결과 표시 여부
rooms/{코드}/participants/{참석자}   이름
rooms/{코드}/responses/{질문}/{참석자}  답 (객관식은 보기 번호, 주관식은 글자)
secrets/{코드}             관리 비밀번호 (아무도 읽을 수 없음)
hosts/{코드}/{발표자}       비밀번호를 맞힌 발표자 기기
```

규칙상 참석자는 **자기 이름**과 **지금 열린 질문에 대한 자기 답**만 쓸 수 있고, 질문·진행·다른 사람 답은 발표자만 바꿀 수 있습니다.
