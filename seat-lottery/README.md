# 우리 반 자리 뽑기 (프로토타입)

`index.html`을 브라우저로 열면 바로 동작합니다.

1. **추첨기**: 학생 번호(또는 이름) 구슬이 통 안에서 섞이고, 한 개가 아래 구멍으로 나옵니다.
2. **사다리**: 교실의 세로줄 8개(4분단 × 짝꿍 왼쪽·오른쪽)에 맞춘 사다리를 매번 새로 긋고, 구슬이 타고 내려갑니다.
3. **자리**: 4분단 × 2열 × 5줄 = 40석 중 도착한 자리에 앉습니다.

- 인원이 40명보다 적으면 뽑기 전에 자리를 눌러 ‘사용 안 함’으로 막을 수 있습니다.
- 학생은 남은 구슬 중에서, 자리는 남은 빈자리 중에서 같은 확률로 정해집니다.
