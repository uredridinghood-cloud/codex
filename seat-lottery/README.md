# 우리 반 자리 뽑기 (프로토타입)

`index.html`을 브라우저로 열면 바로 동작합니다.

1. **추첨기**: 학생마다 동물 얼굴 구슬(16종)이 섞이고, 한 마리가 아래 구멍으로 나옵니다. 이름은 말풍선으로 표시됩니다.
2. **핀볼**: 핀에 튕기며 내려가 아래 칸 8개(4분단 × 짝꿍 왼쪽·오른쪽) 중 하나로 들어갑니다.
3. **자리**: 4분단 × 2열 × 5줄 = 40석. 교탁이 맨 아래, 1줄이 교탁 바로 앞입니다.

- 인원이 40명보다 적으면 뽑기 전에 자리를 눌러 ‘사용 안 함’으로 막을 수 있습니다.
- 학생은 남은 구슬 중에서, 자리는 남은 빈자리 중에서 같은 확률로 정해집니다.
